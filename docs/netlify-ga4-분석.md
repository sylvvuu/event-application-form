### 3-3. 해석

- **연결 검증 완료**: 태그 1개로 6개 이벤트가 자동 수집됨 → 코드 추가 없이 기본 행동 데이터 확보
- **이탈 지점 = 스크롤 → 입력 시작**: 절반 이상이 신청서 영역까지 내려왔지만 입력을 시작한 세션은 4개 중 1개
- **응모 완료가 측정되지 않음**: `form_submit` 0건 — 실제 제출이 없었거나, JS로 제출을 처리해 자동 수집이 안 됐을 가능성 → 전환 이벤트를 직접 심어야 전환율 계산 가능
- **유입 경로 공백**: 링크를 직접 열어 들어온 테스트 트래픽 → 채널 분석 불가
- **표본 한계**: 6명 · 30분, 대부분 본인/테스트 방문 → 수치는 "측정 구조 검증용"이며 실제 고객 행동 결론 아님
